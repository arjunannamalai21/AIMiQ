Problem

Competitive mobile FPS players on mobile devices hit a skill plateau. These players spend hours practicing but see no improvement. Existing solutions are generic (YouTube), privacy-invasive (cloud apps), or don't address the mental aspect of gaming (tilt), leaving players frustrated and unable to reach the next rank.

  • No personalized feedback
  • Time-consuming with cloud processing
  • Mental stress unaddressed
IDEA

AIMiQ: real-time Android AI coach. Captures gameplay, analyzes via OpenCV + TensorFlow Lite, and provides actionable feedback via a non-intrusive HUD—all while processing 100% locally on the device, without any data ever leaving the phone.

Working MVP / Prototype

We have built a functional prototype demonstrating AIMiQ's core coaching capabilities. The screenshots below showcase the key features of our on-device AI gaming coach.

📱 Home Analysis Dashboard

The main dashboard provides a comprehensive overview of your gameplay performance across all seven coaching dimensions. Each metric—Sensitivity Control, Aim Precision, Game Strategy, Gun Selection, Opponent Approach, and Defense Methods—is color-coded (Perfect, Good, Average, Poor) for quick visual assessment. The rating system and match statistics (DMG, Revival, Survival Time) give players immediate insight into their strengths and areas for improvement.

🎯 Game Strategy Analysis

This screen displays a detailed game strategy breakdown with a score of 82/100. The analysis highlights smart rotations, strong positioning, and solid map awareness. The player comparison table shows how you stack up against teammates across key metrics, while the timeline provides context on survival and engagement patterns.

🎮 Sensitivity Optimization

The sensitivity analysis screen generates personalized recommendations based on your aiming patterns. AIMiQ suggests optimal values for General, Red Dot, 2x Scope, 4x Scope, Sniper Scope, and Free Look sensitivity. These tailored recommendations help players achieve better aim control and consistency.

🧘 Mental Health Warning

AIMiQ's integrated mental health feature detects stress indicators during gameplay. This screen displays a warning when stress levels become elevated, with a clear suggestion to take a break. The visual indicators show player stress levels relative to safe zone thresholds, helping players maintain peak mental performance.

Architecture
  • Presentation Layer: Android Activities/Fragments, Custom Views for HUD, MPAndroidChart for data visualization
  • Business: Game Analysis, Strategy, Mental

    • Data Processing Layer:

    Screen Capture

    MediaProjection API.

    Computer Vision (CV)

    OpenCV for frame preprocessing, object detection, and crosshair tracking.

    AI Inference

    TensorFlow Lite for on-device inference using GPU/NPU delegates.

  • Data Storage Layer: Room Database for sessions, EncryptedSharedPreferences for settings
  • Hardware Layer: Optimized for iQOO's Snapdragon 8 Gen 3 (CPU), Adreno GPU, and Hexagon NPU.
Phone-first Thinking

The phone is not just a display; it is the entire computational engine. The app uses the phone's native APIs to capture the screen, its CPU/GPU to process 60 FPS gameplay, and its NPU to run the AI models. This eliminates the need for a PC or cloud server, making the coaching experience portable, private, and low-latency.
